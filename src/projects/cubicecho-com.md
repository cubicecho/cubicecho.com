The page you are on. A small Eleventy site — hand-authored Markdown per
project, plain CSS, no build-time network calls — deployed to GitHub Pages on
push to `main`.

It is here for the same reason everything else is: it is one of the org's
repos, and pointing at it is cheaper than explaining it. If a project card is
wrong, the fix is a Markdown file in `src/projects/`.

Stack: Eleventy, Nunjucks, plain CSS. Brand and theme come from
[cubesite](/projects/cubesite/).
