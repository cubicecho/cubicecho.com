A web editor for the Behringer FCB1010 MIDI foot controller running the
[UnO firmware](https://www.fcb1010.eu/) — presets, global setup, and sysex
transfers, in the spirit of [fcb1010.online](https://fcb1010.online/) but
targeting UnO rather than the stock firmware.

There is no backend: everything runs in the browser over the Web MIDI API, so
the pedal is edited from the machine it is plugged into and nothing leaves it.
Chrome, Edge, or another Chromium-based browser.

Stack: TypeScript, Web MIDI API.
